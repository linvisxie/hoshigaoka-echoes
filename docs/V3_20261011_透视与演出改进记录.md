# 前五关透视与演出改进候选版 0.4.6

本轮按用户要求执行七个优化方向，暂缓第四项 HUD 缩减及布局重排方案。修正关卡间不一致的 HUD 缩放属于用户另行明确要求，不代表执行暂缓方案。

## 已接入的改动

- 五关共用同一视口变换：核心、18 个部署格、HUD 的尺寸和位置不再按关卡改变。三路和部署范围采用可逆的倾斜平行四边形投影，角色、敌人、命中、点击和范围预览一起变换。核心置于最左，路线标识位于核心与战场之间。部署格平时融入地面，选择时显示轻量角标。
- 标题门牌九字校名缩小字距与字号，收进门牌；菜单仍为实际控件。
- 第三至第五关局部出怪路线调整，保留总数 26、25、24；旁路增加威胁，悠真保留跨路普攻与本路贯穿技能。未通过无限增量堆怪替代战术。
- 悠真新增两张实际姿态变化的收弓恢复帧；凛按既有造型补充逐帧素材并接入部署、待机、受击、失能、技能。凛没有普通攻击，其攻击素材不能计为已触发的攻击动画；部署使用施法姿态结合地面反馈，不能宣称独立新绘部署动作。
- 凛恢复权威规划中的 AP 辅助定位：在场回复加成 15%，24 秒主动补给 6 AP，下一次十秒内友军部署减费 2。减费只在成功部署时消费，撤退按实际支付费用结算。观测会成立后可用于第三至第五关重玩，不提前加入首次通关。
- 新增共鸣协奏冷却恢复强化；第五关重玩提供两次真实强化选择，首次教学流程保留。
- 监考者的真实登场、注视目标与预告、低血量加速状态接入地面标记、提示与专属声效；阶段音乐为项目旋律的钢琴变奏。危险提示对应真实状态，不使用伪造倒计时。
- 悬停玻璃按钮柔和过渡、角色世界标签可读性、威胁名称和技能说明改进。教学卡只显示最新一条，避免叠放遮住上路。未重排顶部 HUD。
- 剧情打字增加标点停顿，保持点击完整显示；第五关结尾补写学生会内部记录及资源协调，不提前替代观测会成立事实。

## 仍需精修与验收

本版改善了七个方向，但不能标记“前五关所有最终要求已经全面通过”。角色局部像素、武器边缘及恢复帧衔接仍有精修空间；凛素材与其他角色的像素颗粒还需要进一步统一。静态布景中的地面透视和战斗投影并非每处都完全贴合，背景光照、效果与角色的融合还需审美复核。早期关卡操作节奏与高峰敌人密度是否足够刺激，需要玩家实际反馈。

没有完成全部敌人的全套全新逐帧重绘，没有将资源存在等同于所有动作已经触发。部分底层资源在自动化退出时仍有已有 ObjectDB/资源释放警告，未发现其导致本轮实际操作失败。剧情文字补写和标点停顿不能等同于完整演出精修。音乐音效未经过用户听感验收。

最终概念图视觉品质与用户审美验收均保持待确认；1-6～1-10 和最终 Boss 不在此包交付范围内，不计为完成。
