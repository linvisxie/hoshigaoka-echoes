# 第一章十关可玩候选版 0.5.0

本轮补齐 1-6～1-10 的战斗、关前关后剧情、场景、角色能力、音乐与章节结束流程。后五关沿用前五关的水平三路、透视部署格侧边、动态六瓣核心和玻璃质感 HUD；没有重新倾斜路线或缩小普通阵容 HUD。最终视觉和听感仍待用户试玩验收，本文不代表审美验收通过。

| 关卡 | 场景与主要内容 |

每关均有独立背景和实际出怪时间线。新增八首音乐变奏及技能音效；资源已接入真实战斗和剧情事件。背景基于用户提供的视觉圣经生成并保留原始来源。第七关墙面使用项目正式六瓣 SVG 校徽，消除生成背景中五瓣标志的不一致。

Boss 8000 HP，阶段切换替换技能组并清除前阶段预警和减益；第一阶段标准答案与比较，第二阶段焦虑与错题范围攻击，第三阶段排名、召唤和加速。错题有三秒预警，暂停冻结逻辑计时。击败后的动画继续播放，不随胜利判定停在半途。召唤残响计入实际击退数，结算不再以预设敌人数作为击退数量的分母。

千夏为轻音乐部，结尾解锁后可参与重玩，具有团队速度被动和主动节奏增益。最多五名角色同时在场，第六名作为候补；实验装置不占角色人数，但占实际部署格，可受击、撤回和到期消失。培养列表分页、六人编队预览与角色卡、装备目标按钮和剧情档案滚动均已适配六人。

Boss 首通纪念装备“被划掉的满分试卷”通过装备背包领取，实际提供 5% 冷却恢复，不可强化或分解；领取与章节解锁沿用真实存档服务。
