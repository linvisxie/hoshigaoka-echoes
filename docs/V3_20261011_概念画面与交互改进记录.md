## 已接入实际游戏的变化

- 标题重新恢复原概念图的校门、左侧石柱、右侧钟楼、夕阳与裂隙构图。背景清除原图文字和菜单；Logo、四项菜单、悬停、键盘选择与退出确认分别运行。石柱六瓣校徽和校名由独立绘制完成。关卡选择保留在校园中。
- 引入 Noto Serif 标题字体、Noto Sans 正文字体和 Lucide 单色菜单图标，统一标题、剧情、HUD、强化、结算、培养与设置。培养页清除旧版粗描边与过重蓝色选中底。
- 战斗维持原 3×6 机制和领域逻辑。默认不铺十八个实心框；选择角色后显示轻量站位。生命条统一绿色，低生命转红；卡片区分技能就绪、生效、冷却和再部署状态。
- 强化与结算改为真实原生 Control：三选一、重掷次数、禁用状态、键盘提示、效果与叠层；结算展示实际统计、奖励数值、构筑和回顾，按钮继续交给既有战斗流程。首次强化说明位于卡片上方，避免被遮住。
- 教学与新敌人提示限制宽度、自动换行并延长展示；操作反馈改为原生换行提示条。部署、撤退、技能被拒绝时使用独立错误提示音。
- 剧情采用统一底部对话框、人物名牌与规则头像框；去掉情绪头像下方源图文字，推进按钮不再越出面板。历史与菜单继续阻止背后误推进。
- 第二关使用独立楼梯平台战场，与教室主体形成场景变化；保留原 mapId 和剧情事实。第五关继续采用用户裁决的旧体育馆，正式校徽统一六瓣。
- 近战刀光定位于实际受击目标，箭矢沿攻击来源到目标运动；技能保留独立姿态并增加克制的脚底光与上升光点。技能图集未使用的顶部杂点在绘制时裁掉，脚底注册与武器不变。核心具有受击、危险、最后防线及破碎淡出状态。
- 保留项目原创旋律，使用 VSCO CE 立式钢琴采样重新渲染五首场景音乐；校园与标题使用不同曲目，胜败结算使用独立八秒乐句。新增 Kenney 的悬停、确认、返回和错误音效，保持事件限流、音量设置及淡入淡出。
- 修正培养页顶部学习记录显示为 0 的错误：顶部现在汇总短篇、笔记和档案的实际库存，下方继续分别显示面额与数量。没有修改资源、经验或成长规则。

## 概念对比与剩余工作

标题构图、四项菜单、字体、按钮比例和透明层次已经重新对照原图施工；实际标题和战斗均有原始运行截图。前五关现在具有教室、楼梯平台、测验教室、异常走廊和旧体育馆的可见进程。

仍不能宣称“前五关全面达到最终成品效果”：角色动画衔接、武器边缘与特效层次仍有精修空间；现有像素角色与概念图在头身比例、局部像素密度上仍有差异。UI 已重做，但全部适用视觉元素尚未获得最终审美认可。剧情补写内容仍需要完整文案与节奏审校，音乐需要实际听感评价。用户最终审美验收尚未发生。

自由校园探索未实现，校园是可操作流程 Hub；编队目前调整本关既定角色卡顺序。1-6～1-10、后续可操作角色和最终 Boss 未在本包完成，也没有在菜单中冒充可玩。
