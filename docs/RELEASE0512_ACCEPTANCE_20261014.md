# 0.5.12 设置与鸣谢精修验收 · 2026-10-14

本轮完成用户要求的品牌标题保留、设置页滚动与排序、鸣谢许可证页面、返回按钮对齐，以及继续游戏的柔和点击过渡。

## 交付行为

| 项目 | 实现 |
| --- | --- |
| 标题品牌 | 中文、English 模式均使用原 title_logo.png，位置、大小、发光效果一致；其余界面文字仍按选择的语言显示 |
| 设置卡片 | 高度由 680 增至 745 个设计单位，内部滚动视口固定为 635；底部保存、校园菜单和滚动说明固定在滚动区域外 |
| 设置排序 | 总音量 → 音乐 → 音效 → 文字显示速度 → 显示模式 → 语言 → 关于游戏 |
| 后续扩展 | 每项固定 84 高、间隔 26；新增项目增加可滚动内容，不压缩现有行，不继续加高卡片 |
| 滚动交互 | 鼠标滚轮滚动卡片；滑块关闭滚轮改值，避免阅读时意外修改音量或文字速度。拖动、方向键调值仍可用；键盘焦点可带动卡片滚动 |
| 鸣谢入口 | 设置底部「关于游戏」行的「鸣谢与许可证」按钮进入独立页面，先保留当前设置 |
| 鸣谢页面 | 左侧七个项目；右侧作者、用途、许可类别、文件选择和可选中复制的许可证原文。长文独立滚动，可离线阅读；项目来源按钮由用户主动点击打开 |
| 返回设置 | 左边缘 x=70、宽度 430，与上方项目列表外卡片左右对齐；返回按钮和 Esc 都回设置，恢复滚动位置与原来的标题/校园来源 |
| 继续游戏 | 点击或 Enter 后，选中项以 0.16 秒正弦缓动收淡，再切校园；校园内容以已有 0.32 秒淡入显示。过渡期间锁定重复激活，路由失败时恢复按钮 |

鸣谢数据来自项目实际已有的授权文件：Godot 与其第三方声明、Noto Sans CJK、Noto Serif CJK、Lucide / Feather、Kenney 音效、VSCO 2 Community Edition，以及项目原创 / AI 辅助美术制作说明。总计 13 份本地原文文件。AI 制作来源说明单独列示，没有将其标为开源许可。开发用 GUT 不随 Retail 分发，因此没有把它列为游戏运行依赖。

## 验证

| 范围 | 结果 | 方法 |
| --- | --- | --- |
| 既有全量回归 | 642 / 642；13,363 项断言，42 个脚本 | 隔离数据目录的 GUT |
| 1280×720 | 72 / 72 项通过；20 张截图 | 源码真实渲染、合成视口输入 |
| 1920×1080 | 72 / 72 项通过；20 张截图 | 单独运行同一界面验收，不是缩放 720 截图 |
| 最终 Windows Retail EXE | 32 / 32 项通过 | 自有游戏窗口的实际 Windows 输入、隔离的旧存档副本 |

两种分辨率均覆盖中英文品牌标题、继续游戏动画实际运行与重复激活保护、设置排序、滚动、全部 13 份许可证文本与原文件逐字一致、第三方长文独立滚动、返回设置按钮对齐、返回滚动位置恢复、文字速度保存、标题/校园返回来源，以及页面往返不改存档。

另在测试夹具中追加 12 项未来设置，确认卡片高度保持固定、原行仍为 84 高。这些行只存在于验收脚本，不进入正式游戏。测试发现并修复了滚轮悬停在滑块上时同时改变数值的问题，修复后的滚动往返检查通过。

最终 EXE 验证了中文版设置进入、修改音乐音量、切英文、滚动至鸣谢入口、七个项目逐一打开、返回设置仍保持底部位置、英文标题显示原中文 Logo、继续进入校园、正常退出、重新启动保留英文、切回中文，以及 currencies / stages / inventory / progression / story 五个数据域不变。没有自动打开外部网站；来源按钮的 URL 来自本地项目清单。

中英文标题截图还做了原 Logo 高不透明像素区对照；平均通道差小于 0.04/255，透明叠色与背景樱花变化不作为品牌图变化。两种语言实际调用同一资产、同一绘制矩形。

## 交付与边界

通过项目根目录「启动星丘残响.cmd」启动 0.5.12。设置卡片向下滚动即可看到「鸣谢与许可证」。许可证原文已随 PCK 打包，无网络时可以阅读。

打包前重新备份 0.5.11 正式玩家的主档、备份和设置，以及系统 AppData 中已有的正式文件。玩家文件核对 SHA-256 后原样迁移；QA 存档不迁入正式版，ZIP 不含存档。保留 0.5.11 回退版。源码、最终 EXE/PCK 哈希与验收报告一同记录在 build_manifest.json 和随包证据中。

最终 Retail 专项的正常退出日志没有出现 ERROR、SCRIPT ERROR 或资源保留告警。该结果限定于本轮设置、鸣谢和继续流程；没有据此宣称先前所有战斗退出路径的静态 GDScript 保留问题已全面根治。本轮没有修改战斗数值，也没有重新执行十关战斗或 Boss 主观听感验收。
