# 0.5.9 校园细节与稳定性验收

日期：2026-10-14。保留批准的校园背景、地点与整体风格；本轮没有重新生成背景图。

## 用户补充问题逐项交付

| 问题 | 实现与验收 |
|---|---|
| 1. 角色角标压住经验条 | 经验条右端预留 48 单位，并上移数字角标，避免填充条和编号重叠 |
| 2. 饰品仍有黑底 | 删除项链 SVG 内的实心背景路径，保留金色项链本体；全局使用同一素材。透明角像素测试与最终 EXE 角色装备截图均已检查 |
| 3. 校园菜单按钮位置 | 设置页按钮左边移到 x=300，与上方设置面板左边一致；右侧保存并返回保留原位 |
| 4. 资源悬停说明不一致 | 校园与培养共用 ResourceDescription，读取同一资源定义，显示白色用途与较小的金色楷体短句。最终 EXE 真实鼠标悬停分别验证金币和零件，培养页也留有对照图 |
| 5. 设置齿轮凹陷 | 改为八齿对称矢量图形，保持原框和位置 |
| 6. 手册行不居中 | 四行的图标和文字共享行中心：188、248、308、368；四项字体统一为 19 号，保留批准的图标样式 |
| 7. 空背包武器默认展开 | 空背包首次进入三个类别均折叠；手动展开仍可用。额外修复分类刷新后错误重置折叠状态，以及返回来源丢失的问题 |
| 8. 培养来源档案缺少返回按钮 | 从技能与天赋进入档案时，左下显示“返回培养”，右下保留“返回校园”；返回培养保留角色与列表页。校园入口仍显示原有返回校园。折叠刷新、剧情回看不改变入口来源，Esc 与对应返回培养保持一致 |
| 9. 退出游戏省略号 | 校园菜单文案改为“退出游戏”，沿用原生按钮的水平、垂直居中和原尺寸；退出确认保留。源码视口断言及最终 EXE 截图已验证 |

## 稳定性和流程

- 正常退出时停止音频播放器并清空音频、字体、皮肤和图集缓存，等待渲染同步。最终 EXE 菜单退出没有音频、字体、TextureGL 或 RID 泄漏告警。
- 仍有 26 个 ObjectDB 实例、16 个脚本资源退出告警，不能称作“零告警”。详细探针列出的剩余资源均为 GDScript；静态类依赖仍被引擎保留。本轮没有更换引擎或重写静态类架构。
- 12 轮校园→背包分类→培养→技能→档案折叠→培养→装备→背包→设置→校园往返通过 212 项检查。预热后节点 105、资源 75、纹理 76,838,111 字节保持稳定；静态分配仍有小幅增长，有限轮数不等于长期无泄漏证明。资源、通关、角色与装备数据未改变。
- 修正原有测试夹具里 BattleSession 没有跟随测试节点释放的问题；这是测试对象所有权修复，不混称为线上战斗修复。
- 校园手册按钮悬停加入 0.14 秒柔和提亮，保留现有点击音、金色特殊框及校园樱花。
