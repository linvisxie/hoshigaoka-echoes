# 0.4.7：用户八项实机反馈修复

1. **培养页导航遮挡**：左列明确分为角色列表、横向导航条、学习记录库存。三按钮有独立留白，不再覆盖第三名角色头像；保持返回校园、技能与天赋、装备背包真实可用。
2. **三路向上倾斜**：移除随横向坐标改变高度的项。每条路线从左到右保持水平，上中下仍平行；部署格仅侧边保留斜向透视。角色、敌人、攻击、范围预览与点击一起使用修正后的可逆变换。
3. **强化卡过于靠上**：卡组顶部由参考坐标150移到238，标题、副标题、卡组和操作条分开。三选一、重掷、跳过仍使用同一套命中几何。
4. **头像质感**：依据旧头像和凛的渲染风格分别精修澪、悠真，保留脸型、发型、校服与辨识特征。澪为明确的深紫发与紫蓝眼，白色花饰保留。新增512像素头像供培养页、战斗卡、信息面板及角色说明共用，原像素头像和战斗 Sprite 保留。平滑采样限定在 UI，不改变战斗角色像素采样。
5. **动态核心**：塔架与内部水晶分离。水晶采用16张切面变化的旋转帧，固定高度与中心注册，2.4秒循环；由战斗时钟驱动，暂停或强化选择时一起冻结。静止塔架保留，正式六瓣校徽单独覆盖生成底座的错误花瓣。程序化多面体仅作资源缺失回退，交付默认使用精细逐帧素材。
6. **重试调查**：暂停页新增“重试本次调查”，使用当前关卡与阵容重建战斗，恢复核心、AP、敌人进度、技能及部署状态。本次尚未结算奖励不发放，已领取奖励和角色培养保留。
7. **资源说明**：五种资源悬停0.22秒后显示用途，下面用更小的楷体显示主题短句；文案集中保存在 currencies.json。Windows 使用已安装的 KaiTi/楷体/STKaiti，不复制或再分发系统字体文件。
8. **练习弓适配**：装备模板声明 BOW，悠真声明 BOW、澪声明 SWORD；界面仅提供适配角色，服务层独立拒绝不匹配装配。旧存档的错误绑定加载时在内存中安全清除，装备、强化等级与其他合法装备保留，后续正常保存落盘。没有直接修改正式玩家存档；无效旧绑定也不会继续提供战斗属性。
