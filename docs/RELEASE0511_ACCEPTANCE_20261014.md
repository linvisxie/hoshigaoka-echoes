# 0.5.11 中英文文字切换验收 · 2026-10-14

设置新增「语言」按钮，点击在中文与 English 之间切换，立即生效并单独保存到 settings.cfg。旧设置没有语言字段时默认中文。菜单、第一章剧情、角色技能与天赋、装备说明、资源悬停说明、战斗提示与结算支持英文。玩家填写的名字保留原样；本轮没有增加或替换角色配音。

## 修复范围

| 用户指出的问题 | 最终处理 |
| --- | --- |
| 技能页仍有部署费用、再部署、攻击间隔、冷却等中文 | 修复组合字符串的完整句子、数值模板及局部片段翻译顺序；六名角色页面逐一检查 |
| 序章旁白仍显示「观测记录」 | 补齐无说话人时的备用标题翻译 |
| 培养页第五项资源挤出屏幕 | 英文测量使用实际缩放字号，并依据可用宽度统一调整资源栏文字；五项均验证在视口内 |
| 校园标牌英文越界、垂直不居中 | 英文使用原有无字底图、原字体与颜色；重新设置标牌文字区域并水平、垂直居中，统一学生手册短标签 |
| 学习记录名称与持有数量挤压 | 英文库存改为名称、数量与 EXP 两行；切换按钮使用简洁名称 |
| 英文悬停提示可能残留中文 | 校园美术按钮的 tooltip 单独接入翻译，并加入扫描检查 |

翻译表包含 1,013 条英文映射，统一位于 assets/localization/en.json；生成来源和维护工具在 tools/localization_* 与 tools/build_localization.py。翻译只作用于呈现层，不改 data/ 的权威配置、稳定 ID、经济数值、战斗机制或存档结构。中文校园继续使用原批准画面，英文文字层使用项目已有 campus_textless.png，没有新生成背景图。

## 已知限制

正常退出仍报告静态 GDScript 资源保留：此前为 16 项，本轮新增 GameLocale 后为 17 项。最终英文流程 verbose 日志确认这 17 项全部是 GDScript；没有将此问题宣称为已解决，也没有出现新的纹理、字体或音频释放错误。翻译匹配缓存与 RegEx 对象在退出时主动清理。

中文玩家自定义名字、开发日志及背景美术中的装饰性纹理不作为英文 UI 残留处理。英文全文已接入并验证呈现；正式对外发行前，仍可以继续做母语编辑润色。
