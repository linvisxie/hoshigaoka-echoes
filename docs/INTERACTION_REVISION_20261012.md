# 第一章 0.5.2 交互与战斗节奏修订

本轮针对用户列出的头像、编队、培养、装备、剧情档案、战斗尺寸、节奏和导出包占用问题进行实际修改。仍为成品候选版，用户视觉、听感与好玩程度的最终验收尚未完成。

## 已接入游戏

- 结衣、纱良、千夏：保留原头像近景取景，使用内置 imagegen 去除不透明背景；新增与既有身份一致的全身立绘，接入技能页、角色装备页及实际剧情。透明图片经实际游戏截图检查，未用全身图缩小冒充头像。
- 出战界面：去除轮换按钮；左键单击选择/取消实际参战，薄矩形高亮；拖动角色卡排序，插入位置平滑移动，拖动释放不触发取消。空阵容不能开始战斗。
- 培养：返回技能、背包时保留选中角色及所在页，返回校园清除此临时选择；左侧学习记录可直接选择；第三档为全部投入，以持有数量和当前等级上限限制预览，升级后事务保存。
- 布局：技能与天赋移至升级/突破下方，旁边新增角色装备。角色装备左侧完整立绘，右侧武器/饰品/校园纪念物固定三行和背包入口。原背包按三类展开，各装备带类型图标；错题集属性、当前持有者、装备按钮不再叠在同一文字区。
- 既有领域层已经限制每人每槽一件、武器职业匹配、同槽替换保留旧装备；本轮复用该规则，未新建不兼容存档体系。
- 剧情档案：序章直接回看，第一章可展开，按关卡数字及调查前/后排序。第二章未制作，未添加不能使用的第二章假入口。
- 战斗：依角色透明边界统一显示比例；退场采用相同尺寸规范。普通/精英/Boss逐级增大，Boss顶部血条增加高度、阶段与色彩辨识。残响锚点增大并提亮；重绘底座移除旧花形，只叠加一次正式六瓣徽记。
- 强化：重掷/跳过距卡片下缘增至80设计像素。胜利结算延后至2.8秒，留出1.5秒胜利动作和敌人消散时间。
- 节奏：十关计划敌人数依次为7/11/31/30/29/32/32/32/32/85；同路成对增援及压缩出怪空档。撤退等待缩至12～15秒；Boss基础速度0.18→0.13，攻击150→170，攻击间隔2→1.65秒。不是简单加速整个游戏。
- 音乐：沿用原创章节动机及已有CC0钢琴采样，新编三阶段Boss音乐，148/156/164 BPM，加入原创鼓组、低音和分解声部。音频参数与来源随包提供。

## 验证与边界

- 真实Windows引擎窗口，从新游戏连续通过十关、剧情、培养、奖励和结尾；耗时约25分钟，正常领域时间/AP，无战斗作弊。前九关资源足够首次Boss培养，未借用Boss奖励。首次固定部署路线曾在1-3失败，调整旁路支援站位后重新从新游戏连测通过，失败记录保留。
- 609项回归、11378条断言通过。旧战术机制测试显式使用0.5.1固定关卡夹具；当前出怪数据与实际可通关性由新数据检查和上述完整实机流程覆盖，未把旧夹具当作新平衡验证。
- 新交互经真实Windows窗口事件验证：培养页恢复、材料选择/投入、装备分类、剧情立绘、编队点击及拖动、实际战斗阵容过滤。最终Windows导出包另经OS鼠标键盘验证重试、三阶段Boss、强化、胜利、返回与正常退出；报告与最终PCK哈希绑定。
- 自动化测试退出仍报告ObjectDB/资源未释放告警，原始日志保留；不把这些日志描述为完全无告警。最终退出是否正常以导出包独立报告为准。
- 实机通关不等于每种阵容都平衡，也不能替代用户对压迫感、音色、像素细节和视觉方向的试玩判断。这里不宣称美术100%完成或用户已验收。

## 资源与空间保护

新图使用内置imagegen，原始结果、参考身份、提示词、透明处理与SHA记录在工程tools/source_art和docs。音乐仅用既有合法采样及原创合成，未新增付费软件、未知许可音源、字体或模型。

导出保留脚本仅清理dist内明确识别的旧导出目录及对应项目ZIP；路径解析后检查位于dist内且无重解析点，先按SHA备份旧存档再删除。只保留当前0.5.2和最近0.5.1回退版。源码、Git历史、工具、素材源、配置、正式存档不在清理范围。

统一启动器使用新版本独立玩家目录，原玩家存档原样复制并验证SHA；自动化存档不会覆盖玩家数据。ZIP不含玩家或测试存档。
