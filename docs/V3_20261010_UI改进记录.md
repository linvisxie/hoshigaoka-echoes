# 前五关 UI、HUD 与 UX 改进记录

2026-10-10。接续上轮前五关连续流程候选版；本轮仍不将美术或用户审美验收标记为完成。

## 实际交付变化

- 战斗使用原生 Control HUD：六瓣校徽、关卡地点、波次与预告、AP 条、角色头像卡、HP 与技能冷却、选中角色技能/撤退面板。保持原有领域战斗结算。
- 部署保持 3×6；平时无十八个实心部署框，选择角色时显示轻量位置提示。角色与核心按路线层次显示。
- 暂停菜单具备继续、操作说明、三路音量、设置保存和离开确认；确认前不会离开战斗。模态界面拦截背后点击。
- 校园菜单、带场景预览的关卡选择、统一按钮与面板；养成导航保留选中角色。
- 装备列表支持滚动；已装备、资源不足、没有待领装备时有禁用状态和原因提示。领取、强化、卸下和重新加载保留实际属性效果。
- 剧情文字速度可调，自动状态明确；历史与菜单阻止误推进；设置从标题进入后返回标题。
- 第五关采用旧体育馆战场与对应剧情背景。校门石柱、HUD、菜单和核心统一六瓣正式校徽。
- 两名角色从原始绘制图集重新导入为 96px 帧，保持造型、动作和脚底注册；部署、技能、胜利仍为独立绘制姿势。未将增加像素数视为美术验收通过。
