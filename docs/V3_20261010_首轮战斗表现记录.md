## 本轮实际变化

- 部署机制保持 3×6；平时不再显示十八块实心蓝格，选人时显示轻量合法角标/非法叉，悬停单格提示，原有范围预览保留。
- HUD 改为分组顶部面板与底部头像卡；移除大面积遮光，增加脚底阴影并按路线交错绘制双方，减轻遮挡。
- 核心由粉色竖线改为六瓣星花/晶体/轨道基座；接入危险染色、受击反馈和击破变暗。完整击破演出仍未完成。
- 雨宫澪、神谷悠真使用新绘制姿态图集，切为 64×64 的待机/移动/攻击/受击/退场条带；攻击有真实姿态差别。部署/主动技能专用帧仍缺，角色品质和连续性仍需精修。
- 1-5 单独接入扩大地面比例的背景，解决原图人物落在墙面上的构图问题；其余关卡未批量替换。
- 原创合成两首循环 BGM 和十四种音效，接入标题、战斗、部署、选择、撤退、命中、受伤、强化、波次、核心与结算；12 路音效池及按音效去重。治愈音效已接接口，但本次 1-5 无治疗角色，未动态覆盖。
- 限制最高帧率为 60；测试与试玩入口隔离存档。原有存档、标签未改变。

## 实机证据与限制

`docs/art_screenshots/v3_20261010/` 保存原始 Windows Godot 渲染视口、对应 JSON、十张攻击序列、通关报告，以及导出 EXE 的原始帧。输入由脚本自动完成，不能当作人工试玩。截图不是桌面截屏，不是美术拼贴；对比图和 GIF 是另行标注的整理产物。窗口大小曾在录制中发生变化，部分原帧含右侧黑边，不裁改原始证据。

1-5 正常逻辑自动运行 159.2 秒，5/5 波、击杀 8/8、防线 3/3、零漏怪、零失能；实际出现强化三选一并选择首项。捕获连续攻击十帧。覆盖到攻击、受击和敌人死亡，不代表所有角色/所有状态动态验收。

回归：28 脚本 / 580 测试 / 9409 断言通过；正式主存档和备份前后 SHA256 一致。已有退出时 ObjectDB/资源泄漏警告仍待修复。完整结果为 `D:/星丘残响/_testenv/v3-final-regression/result.json`。

Windows 导出 `dist/v3_visual_preview/` 的 EXE/PCK 已检查 406 项包内完整性，标题/战斗/选关各启动六秒，无脚本错误；测试、工具、文档未进入 PCK。这是 Prototype 预览构建，未冒充正式发行版。导出报告 `export_report.json` 与引擎通关报告分别保留。

导出 EXE 的 WASAPI 扬声器回录为非静音，baseline RMS 0.00000105、运行 RMS 0.1383、peak 0.9901、削波样本 0。回录可能混入其他应用声音，采集有 discontinuity 警告；同时保留游戏播放状态以辅助归因。这证明运行有声音输出，不能代替音乐审美和人工混音验收。未使用物理麦克风。报告与 WAV 位于 `D:/星丘残响/_testenv/v3-export-audio/`。

## 来源与复现

人物源图与导入脚本位于 `tools/source_art/`、`tools/import_mio_v3.py`；逐人物来源记录为 `docs/mio_v3_source_record.json`、`docs/yuma_v3_source_record.json`。背景来源记录为 `docs/gym_v3_source_record.json`。内置 image_gen 具体模型身份未由工具暴露，不猜测型号。已核对 [OpenAI 服务条款](https://openai.com/policies/terms-of-use/)；生成输出条款不能代替输入概念图的权利核实，目前只列内部候选，用户提供原图的底层权利未独立确认。

音乐为 `tools/build_audio.py` 原创旋律及合成，没有外部采样/旋律；见 `assets/audio/source_record.json`。核心 SVG 是工程自行绘制。既有字体、旧素材继续沿用原来源清单，未重新宣称整个资源库商用许可全部审核通过。

新增工具依赖安装于 `D:/星丘基础/python-libs`：numpy 2.5.3（BSD-3-Clause）、SoundCard 0.4.6（BSD-3-Clause）、cffi 2.1.1（MIT No Attribution）、pycparser 3.11（BSD-3-Clause）。它们仅用于制作/验证，没有打入游戏；许可证随各自 dist-info 保留。音频脚本使用 Python 3.13，图像整理使用已有带 Pillow 的 Python 3.12；不可混用 numpy 的 cp313 二进制。

复现视觉录制：将 APPDATA 指向工程外 `_testenv` 子目录，运行 Godot `--path . --resolution 1280x720 res://tools/record_visual_slice.tscn -- --autoplay --autoplay-hold-upgrade`。这是正常 Windows 渲染与战斗时钟，不是无头视觉验收。制作音频设 PYTHONPATH 指向工具库后运行 `tools/build_audio.py`；扬声器验证运行 `tools/verify_audio_windows.py --output <_testenv路径> --exe <导出EXE>`。
