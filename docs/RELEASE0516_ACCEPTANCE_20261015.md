# 0.5.16 设置、阅读与装备预览

本轮最终仅保留四项功能。按用户要求，取消剧情档案搜索、筛选与阅读进度改动，恢复原列表；取消统一按钮反馈和页面过渡改动；移除“跳过已读”。

## 最终改动

- 设置新增动态效果强度：关闭、柔和、标准。控制标题与校园樱花、校园枝叶、人物轻动、天空残响与地点灯光；按钮反馈和页面过渡继续使用 0.5.15 的实现。关闭时清除已绘制的樱花，避免残留静态粒子。
- 设置新增自动阅读基础停留时间，范围 1–6 秒。长句显示完成后适当增加阅读时间，中英文分别按字数和词数计算；历史、自动、菜单和下一句按钮沿用旧布局。没有新增跳过功能。
- 装备换装、卸下及强化先展示预览，显示装备名称和强化等级、人物当前与操作后属性、差值；跨人物转移同时显示两名角色。强化显示消耗及剩余资源，资源不足不能确认。预览在存档深拷贝上计算；取消不写入存档，确认时再次检查状态并使用原有事务操作。
- 校园地点悬停提示可用交谈状态：新交谈数量、全部已读、尚无可用交谈。继续调查保留现有目标关卡提示。提示依据真实解锁与已读状态，不预告未解锁内容。
- 新设置保留固定卡片尺寸和行高，通过滚动查看后续内容。修正英文装备成功提示中的中文残留。

## 撤销核对

`scenes/menus/archive.gd`、标题页、SceneRouter、按钮焦点辅助、校园美术按钮和 CampusScreen 六个文件，与正式 0.5.15 提交 `6772a9a` 按规范化换行逐字比对一致，见 `restored0515_report.json`。GameSkin 仅新增环境动效选项读取与强度换算，原按钮样式与悬停逻辑保持原样；校园点击等待时间也已恢复。
