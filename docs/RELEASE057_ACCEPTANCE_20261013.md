# 0.5.7 校园 Hub 验收报告

本轮把用户批准的最后一张校园概念图落实为游戏校园主页。建筑、夕阳、人物、公告板、地点标牌、学生手册、右下调查卡和左下金色文案均沿用批准画稿的位置与外观；右上资源使用原有学园币、装备零件图标与玻璃面板。

## 交付功能

| 部分 | 实际行为 |
|---|---|
| 教学楼、观测会活动室、弓道场、保健室 | 可点击进入对应地点记录面板，展示已解锁的真实事件；尚无事件时显示空状态 |
| 雨宫澪 | 点击人物可进入活动室记录 |
| 调查公告板 | 标牌和实体公告板均可展开、收起右下当前调查卡 |
| 当前调查 | 跟随存档更新关卡、名称和线索，继续调查进入原有剧情与出战流程；待完成的战后剧情优先恢复，第一章完成后进入已开放关卡重访 |
| 校园漫游 | 中央阶梯入口打开地点选择；科学部、旧校舍、轻音部等已有事件地点随主线进度出现 |
| 学生手册 | 角色培养、角色装备、关卡记录、剧情档案、继续调查均接入原有功能 |
| 提示与资源 | 保健室新交谈仅在结衣事件解锁且未读时出现；资源显示实时存档数值，交谈不消耗资源、不额外奖励、不解锁后续关卡 |
| 输入 | 原生按钮支持悬停、按下、键盘焦点；Esc 关闭地点/漫游面板，主页 Esc 打开校园菜单，退出需确认 |

为严格保留原稿书写与装饰，原稿切片作为独立原生控件皮肤，背景仍使用批准画稿。当前调查的动态文字重新排版，避免中文行高导致裁切。清底图只用于控件遮挡处与收起调查卡后的场景恢复，没有重新生成整张主页来替换批准图。

地点采用现有区域背景加记录面板的点击交互；本轮没有制作自由行走系统，也没有凭空增加未写好的支线。人物和场景画稿保持原图静态表现。

## 对照与验证

- 1672×941 源码实机视口截图、1-3 参考状态、鼠标未悬停时，与批准画稿比较。明确排除资源矩形 `(1337,24)-(1590,72)` 和交谈状态矩形 `(1284,426)-(1434,506)`；其余 **1,549,208 像素，差异 0，一致率 100%**。这不是所有存档、所有动态状态或缩放分辨率的全图逐像素保证。
- 最终 Windows Retail EXE 以真实 Windows 鼠标/键盘、1280×720 运行，**31 项检查全部通过，17 张实机截图**。使用历史真实通关档的隔离副本，验证地点、结衣交谈落盘、资源和关卡不变、公告板、各功能入口、Esc 与正常退出。未操作玩家正式存档。
- 源码 UI 驱动分别在 1672×941、1280×720 通过；明确使用隔离的领域结算夹具构造 1-3 状态，属于 UI/流程测试，不冒充重新手玩通关。
- 完整 GUT：**37 个脚本、628 个测试、12,051 个断言全部通过**。本轮新增校园事件门槛、已读状态和查询不污染存档验证。
- 本轮没有重跑整章十关战斗、Boss 平衡或音乐听感验收，相关行为沿用上一版。

实机截图与原始报告随版本放在 `实机验证/`，打开 `实机对照.html` 可逐张查看。原图对比脚本为 `tools/verify_hub_pixels.py`。

## 已知问题与边界

功能运行过程中未出现脚本或解析错误。GUT 仍报告 5 个孤立节点及退出时资源残留；正式 EXE 正常退出码为 0，但菜单退出仍打印已有的 RID/纹理及 21 个资源残留告警。本轮没有把这些告警算作修复，也没有将“正常退出”描述为“零告警”。完整日志保留。

金币、材料、当前关卡与已读交谈必须随真实存档变化，因此与概念图上的示例数字和示例关卡有合理差异；悬停、按下与键盘焦点也会产生交互反馈。

## 存档与版本

发布工具先校验并备份最新 0.5.6 玩家主存档、备份档、设置，逐文件 SHA-256 验证后迁移到 0.5.7；正式 AppData 只做保全，不覆写。测试夹具从不进入发布存档。ZIP 不含任何玩家存档。

统一启动器更新至 0.5.7，仅保留 0.5.7 与最近可回退的 0.5.6 发布包；旧 0.5.5 导出及 ZIP 在保全其存档后清理。源码、开发工具、素材、配置均保留。具体执行结果见存档 checkpoint 与版本保留报告。
