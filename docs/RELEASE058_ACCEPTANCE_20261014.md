# 0.5.8 校园精修与返回流程验收

## 本轮逐项结果

| 用户问题 | 完成内容与验证 |
|---|---|
| 1. 保健室标牌被遮挡 | 移除盖住右上角的错误清底补丁；恢复完整牌框。未解锁/已读状态只隐藏“新的交谈”字条，金色装饰灯不再挖掉牌框 |
| 2. 角色装备改装备背包 | 文案改为“装备背包”，直接进入持有装备、分类与强化界面；不再进入单角色装备面板 |
| 3. 校园漫游重复地区 | 排除主页已有的教学楼、活动室、弓道场、保健室；教学楼告示栏/学生会室、剑道场/图书角已有记录分别归入主页教学楼/活动室入口。漫游暂时仅放已解锁的科学部、轻音部、旧校舍等额外地点；无额外地点时显示空状态 |
| 4. 资源栏不一致 | 两个框共用同一矢量素材，均为 119×38、同一纵坐标和相同斜角；同类图标均拟合到 22×22，沿用原有金币与零件图案；数量在栏内垂直居中 |
| 5. 设置页缺少校园菜单 | 从校园进入设置时，“保存并返回”左侧增加“校园菜单”；保存设置后返回校园并显示原有菜单，含继续留校、返回标题和退出确认。标题进入设置时不显示校园菜单 |
| 6. 文字模糊 | 原稿地点、校名、公告板、金色题词等保留原有字形、位置、间距和色相，局部使用线性采样与受限边缘增强；资源和动态调查文字使用清晰的原生字层。学生手册四项用同一宋体、19 号字和统一垂直居中，避免新旧 caption 大小不一 |
| 7. 淡樱花动效 | 复用标题页的 22 片淡粉花瓣、透明度、漂移和旋转参数，在校园背景与交互控件之间播放；不挡鼠标、不遮按钮、不改建筑构图 |
| 补充：弓道场/保健室/公告板字位漂移 | 撤掉改变原稿基线的试排，恢复原图透视及字位；只增强字缘，保留原有标牌内的布局 |
| 补充：文字背后黑块 | 修正着色器重复叠乘纹理颜色的错误。8 处文字区域亮度对照通过，未再出现矩形压黑；完整截图可查看 |
| 补充：资源和齿轮黑底 | 图标共享入口去除与外边缘相连的精确导出底色，保留封闭暗部与所有非底色像素；齿轮改为无额外黑方块的原生矢量样式 |
| 补充：角色培养页大量小图标黑底 | 同一共享修正覆盖金币、学习记录、徽章、结晶、零件、生命、攻击、防御及按钮小图标；32/64 两种源尺寸均验证，原 PNG 源素材未覆写 |
| 补充：继续游戏错误进入关卡 | 标题“继续游戏”始终先进入校园；不清空未完成剧情节点、待调查关卡和战后剧情。玩家通过校园继续调查恢复流程 |
| 补充：出战确认 Esc 返回错误 | 主线/校园继续调查进入时返回校园；关卡记录进入时返回记录。页面返回按钮与 Esc 一致。正式 EXE 发现并修复输入回调中切场景的闪退，切换延迟到输入处理结束后执行 |
| 补充：空阵容红字遮按钮且不消失 | 底部中央独立提示区域，至少选择一名角色的提示显示 2.5 秒、最后 0.35 秒淡出；复用同一标签，重复点击不堆叠；禁止空阵容进入战斗 |
| 补充：校园随记无法折叠 | 与章节一致增加 ▾/▸ 展开收起，隐藏或显示四列已读记录；不修改已读状态或重复奖励 |

校园漫游当前仍是额外地点的记录入口，没有提前实现尚未提供画稿的其他校园 Hub 大场景切换；后续区域可沿该入口扩展。原稿栅格字只能增强已有边缘，不能凭空恢复不存在的高分辨率字源；本轮没有把地点招牌换成另一种字体，也不宣称所有存档画面逐像素等同旧版。

## 验证证据

- GUT：38 个脚本、630 个测试、12,144 个断言通过。新增共享图标透明底、非底色像素保真、缓存及缺图回退验证；校园漫游去重也纳入测试。
- 源码视口：1672×941、1280×720、1920×1080 各 60 项界面/流程检查通过。使用明确的隔离结算夹具，不冒充重新手玩通关；验证四项字号、资源框几何、校园随记折叠、未完成出战继续游戏、两种返回来源、空阵容提示定时消失。
- 最终 Windows Retail EXE：校园/培养/设置/档案等 36 项检查，以及以当前玩家档副本进行的导航 21 项检查，通过真实 Windows 鼠标键盘验证。两类测试独立目录，未回写玩家进度；合计 30 张截图。
- 字体区域无黑底回归检查、花瓣跨帧变化检查通过。该自动检查用于发现压黑与缺少运动，不能代替人工审美验收；实机截图已逐项检查。
- 本轮没有重新验收十关战斗平衡、音乐听感或完整新档通关，相关玩法沿用上一版。
