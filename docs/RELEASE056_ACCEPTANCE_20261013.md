# 星丘残响 0.5.6 · 六项界面精修

日期：2026-10-13。

| 反馈 | 修改结果 |
|---|---|
| 校园首页底部蓝字 | 移除“放课后 · 第一章调查中 / 第一章调查结束”整行，保留左下方金色题词。 |
| 姓名输入框光标不闪 | 开启 0.5 秒间隔闪烁；进入页面后激活编辑状态，光标使用清晰的浅色与 2 像素宽度，保证缩放后仍可见。 |
| 关卡记录提前显示后续内容 | 正式版只列出已解锁关卡：新档只有 1-1，通关后逐步出现下一关，失败不会解锁。已通关关卡仍可重访。沿用所有前置关卡必须通关的校验。开发专用 Alpha 预览入口保留原有纪律，不对正式玩家开放。 |
| 雨宫剧情小头像与战斗不一致 | 移除剧情对白的旧表情头像覆盖逻辑，全部使用战斗共用的 `ArtRegistry.character_portrait`；大型剧情立绘不变。 |
| 三路标识美化，禁止新增箭头 | 新绘制六瓣花玻璃徽标，优化边框、高光、尺寸及文字底板；保留“上段 / 中段 / 下段”，未加入方向箭头。 |
| 标题门牌校徽的方形底块突兀 | 去掉越过门牌边框的纯色方块；从原门牌取用内部材质，原有金属边框保留，校徽缩至框内并调整金色明暗。 |

## 验证

- 完整 GUT：626 项测试、12,037 项断言通过。新增关卡列表回归检查新档、失败、首胜及第二关胜利后的逐步展示。
- 最终 Retail EXE 在 1280×720 的真实 Windows 窗口中，完成标题、已通关校园、新游戏、姓名输入、序章雨宫对白、新档关卡记录、培养、装备、实际 1-1 战场与暂停的操作和截图。
- 光标使用连续原始 Windows 截图检查输入框区域的明暗变化，另提供截图合成动图。静态属性设置没有被当成“实际闪烁”的证据。
- 关卡页实机截图只有 1-1；雨宫剧情头像及三路徽标已逐图查看。战场截图前核对实际探针关卡为 1-1，避免将菜单误标为战场。门牌另附实机截图放大细节。
- 本轮没有重跑十关连续流程或 Boss 战；这些仅是上一版的历史验证。当前修改集中于显示与输入，以及关卡列表可见性。
- 本次在暂停的战场使用正常 Windows 关闭窗口结束，进程退出码为 0，没有脚本或解析错误；日志仍有 2 个 ObjectDB 实例退出告警。既有菜单路径和 GUT 的资源释放告警未在本轮修复，不能宣称零告警。

引擎输入框编辑与闪烁行为参考 [Godot LineEdit 官方说明](https://docs.godotengine.org/en/stable/classes/class_lineedit.html)。实际通过情况以上述运行证据为准。
