# 0.5.14 焦点、过渡与校园交互精修

修正用户报告的八项问题，保留现有构图、文字、菜单位置与点击矩形。

1. **浅色框残留**：区分输入方式。鼠标点击或移动后隐藏焦点框；Tab、方向键、Enter 与手柄仍能显示键盘焦点。关闭弹窗恢复逻辑焦点时，不再给鼠标操作留下矩形。按钮销毁时自动移除焦点订阅，未增加全局按钮缓存。
2. **继续游戏黑屏与过渡过快**：继续游戏和设置共用 0.22 秒点击反馈、0.55 秒柔和过渡。标题页完整绘制后才采集上一帧，由场景之外的临时图层覆盖切换间隙，进入页面后淡出并释放。过渡期间拦截重复输入，正常关卡与剧情路由规则不变。
3. **留在这里音效不同**：鼠标按钮统一调用现有 `select → ui_confirm`，与其他确认按钮使用同样的音量路径；键盘 Esc 返回音效保留原有语义。
4. **樱花过淡**：标题与校园共用 42 枚、三层景深的绘制规则，适度增加可见数量、颜色与透明度。粒子位于界面下方，不遮挡文字。
5. **枝叶与纸页不明显**：提高局部枝叶和前景偏移。纸页作用于左侧“放课后观测记录”公告板的两张便笺下半部，固定上缘附近，增强下缘摆动。标题、资源栏、学生手册、调查卡与左下角声波提示继续受保护。
6. **人物边缘粗糙**：移除硬轮廓网格及补景边条，改为原画的柔和局部融合。人物脚部与外轮廓不做硬切割，保留原始配色；闭眼仅转移此前眼睑编辑的差值。未再生成或替换人物原画。
7. **天空缺少流动**：既有紫色轨迹上增加缓慢移动的亮点与短尾迹，星点增加间歇十字微光，避开资源栏。
8. **地点与新记录反馈太弱**：提高活动室等门窗悬停暖光，将地点牌高亮与未读光点移到正确显示层。未读交谈依据真实解锁与已读状态；有未读校园记录时，公告板两张纸角周期轻抬。调查内容首次出现或关卡变化时，照片先浮现，文字随后出现；再次返回相同调查不会重复更新反馈。

## 验证与边界

- GUT：44 个脚本，646/646 测试，13,385 个断言通过。新增输入方式、焦点保留及按钮销毁后信号清理检查。
- 中英文、1280×720 与 1920×1080：每个分辨率 30 项源码渲染和合成原生 Control 输入检查通过。覆盖两个标题入口的过渡、确认音效计数、返回后的逻辑焦点与鼠标框隐藏、键盘提示、悬停强度及存档不变。
- 像素对照：隐藏樱花后，五个保护区域在开关局部动效时保持最大像素差 0；人物衣服内部平均亮度差小于 1%。独立帧序列中，天空、纸页、枝叶均有可测变化；关掉樱花排除了粒子经过造成的误判。
- 切换连续帧：源码在每个语言与分辨率下，分别采集继续游戏和设置的连续画面。最终 EXE 另以真实 Windows 输入采集 18 帧，未出现清空画面；截图及每帧亮度随包提供。采样通过不能证明所有硬件与任意时序下绝无闪屏。
- 最终 EXE 使用隔离的正常通关存档副本，49 项实际 Windows 检查通过，验收地点、未读保健室交谈与真实已读保存、资源提示、培养、装备、档案、设置、返回和正常退出。EXE/PCK 哈希绑定于实机报告。
- 动效对照 GIF 是源码真实渲染截图的派生预览；其中 `unread_fixture` 为不写入存档的纯表现夹具。实际 EXE 的未读反馈使用正常通关存档中的真实事件状态。自动化验收不等于人工试玩或人工听感评价。

实机测试曾复现清空缓冲黑帧，并发现零面积纸角三角形。发布前分别通过完整绘制帧采集和最小抬角门槛修正；失败证据保留于工程外 `_testenv/polish0514`，不会冒充通过结果。

正常退出仍报告 17 项资源保留；详细日志列出 30 项 ObjectDB 对象，类型为 GDScript/GDScriptNativeClass，未列出动画节点、纹理或 Tween。资源数量与旧版一致，本轮不宣称解决该历史问题。新焦点辅助脚本随按钮生命周期释放，避免额外静态脚本资源保留。

版本交付会按哈希备份和迁移真实玩家存档与设置，保留 0.5.13 回退。测试存档不进入发布 ZIP。旧美术来源声明继续提供；0.5.14 不再使用硬边人物补景。
