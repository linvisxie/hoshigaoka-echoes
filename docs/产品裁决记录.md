## 裁决 A：再部署后的 HP 口径

- **裁决编号**：DEC-A-0001
- **裁决日期**：2026-10-09
- **状态**：**已裁决 · 已实现 · 已有回归测试**
- **适用阶段**：Prototype P0.3 起（含 P0.4 起的全部角色）

### 裁决内容

1. 主动撤退或失能离场后，角色经过正常冷却再次部署时，**以当前最大 HP 满血入场**。
2. **不继承**上一次部署的剩余 HP。
3. 撤退只返还**原始部署费用的 50%**；失能返还 **0 AP**。
4. 再部署**依然需要支付正常部署费用**。
5. **不提供**额外 AP、免冷却或其他隐藏加成。

### 依据与背景

- 主规格 D-9「角色重新部署」只规定「主动撤退返还 50% 原部署 AP」「主动撤退后进入正常再部署冷却」「角色死亡不返还 AP」，**未规定重新部署时的 HP 口径**。
- 主规格 D-27「角色死亡」规定 HP ≤ 0 时角色离场并进入重新部署冷却，同样未涉及 HP 继承。
- 因此 P0.3 施工时以「最小裁决」实现为满血重建并登记为待裁决项（见 `docs/P0.3_验收报告.md` 第 2.5 节）；本记录将其**升格为正式裁决**。

### 实现位置（可追溯）

| 项 | 位置 |
|---|---|
| 退款比例配置 | `data/balance.json` → `combat.retreat.refundRate = 0.5`、`refundOnIncapacitated = 0.0` |
| 再部署冷却配置 | `data/balance.json` → `combat.redeploy.defaultSeconds = 20`；角色级 `characters.json` → `redeployTime` |
| 退款计算 | `scripts/domain/battle/stage_runtime.gd` → `compute_retreat_refund()`（FLOOR 取整，可传入比例覆写） |
| 撤退结算 | `scripts/domain/battle/stage_runtime.gd` → `withdraw_character()` / `withdraw_character_by_id()` |
| 失能离场与冷却 | `scripts/domain/battle/stage_runtime.gd` → `_cleanup_dead()` |
| 满血建实例 | `scripts/domain/battle/character_runtime.gd` → `from_config()`（hp = max_hp、attack_cooldown = 0、阻挡列表为空） |
| 冷却推进 | `scripts/domain/battle/stage_runtime.gd` → `_tick_redeploy_cooldowns()`（仅在固定逻辑步内推进） |

### 回归测试（可执行依据）

- 不实现「保留剩余 HP 再部署」；

- **裁决编号**：DEC-B-0002

- **状态**：**已裁决 · 已实现 · 已有回归测试**

## 裁决 C：远程角色跨路线攻击（正式取代旧版同路线限制）

- **裁决编号**：DEC-C-0003
- **裁决日期**：2026-10-09
- **状态**：**已裁决 · 已实现 · 已有回归测试 · 已有实机证据**
- **适用阶段**：Alpha A0.5 起（含 Prototype 与全部正式关卡）；首位实现角色为**神谷悠真**
- **批准来源**：项目负责人本轮明确批准的设计变更（《星丘残响》下一轮总指令 · 第一阶段）

### 裁决内容

**前线角色（behavior = FRONTLINE，如雨宫澪）：**
1. 普通攻击**只能命中自己所在路线**。
2. 阻挡仍只能作用于**本路**。
3. **不改变**雨宫澪的阻挡数（2）与原有技能的已锁定机制。

**远程角色（behavior = RANGED，如神谷悠真）：**
1. 普通攻击允许命中**自己所在路线及相邻路线**。
2. 位于**中路**时，可以选择上、中、下三路的合法目标。
3. 位于**上路**时，最多攻击上路和中路。
4. 位于**下路**时，最多攻击下路和中路。
5. **不允许上路角色直接攻击下路**（laneDelta = 2 一律拒绝）。
6. 每次普通攻击**仍只选择一个目标**（targetLimit = 1）。
7. 跨线**不会**增加攻击频率，也**不会**自动复制攻击次数。

**神谷悠真的具体射程（首位实现角色）：**

| 项 | 值 | 性质 |
|---|---|---|
| 本路前方射程 | **4.0 格** | 保留 V2.1.4 表 28 原值 |
| 相邻路线前方射程 | **3.0 格** | **第一轮候选平衡值，需实战验证** |
| maxLaneDelta | 1 | 最多跨相邻一条路线 |
| allowCrossLane | true | 必须由数据**显式声明** |
| targetLimit | 1 | 每次只打一个目标 |

8. 距离仍以**逻辑格（tile）**计算，**不得**用屏幕像素判定（V2.1.4 LOCKED 度量规则）。
9. 攻击方向必须符合原有**面向敌方入口**的规则（`direction = forward`）；角色身后的目标不可攻击。
10. 多路目标同时存在时，继续遵守**当前有效的敌人目标优先级规则**（D-11：① 最接近防守核心 ② 当前正在阻挡 ③ 更早进入攻击范围）。

### 架构要求（已实现）

- 新增**可配置的攻击路线覆盖能力**，通过角色数据显式声明：
  - `attackRange.maxLaneDelta` — 允许的路线差；
  - `attackRange.rangeTiles` — 本路线射程；
  - `attackRange.adjacentLaneRangeTiles` — 相邻路线射程；
  - `attackRange.allowCrossLane` — 是否允许跨线；
  - `attackRange.targetLimit` — 单次目标数量。
- **不得**仅仅通过修改 `classType` 或 `behavior = RANGED` 就让所有远程单位无条件获得同样的跨线范围。已在 `StageRuntime` 构建期加入一致性校验：声明自相矛盾时**报错**而非静默退化（见下方测试）。
- **复用**现有射程与目标选择系统（`CharacterRuntime.can_attack_lane()` / `attack_range_for_lane()` / `is_target_in_attack_range()` + `StageRuntime._select_target_for()`），未重复建设战斗逻辑。
- 本次**只修改玩家角色的指定攻击范围**，敌人的攻击范围**未随之变化**（已用测试与实机双重验证：试卷飞灵仍为射程 3 格、maxLaneDelta = 0）。

## 裁决 D：攻速百分数 → 攻击间隔换算口径

- **裁决编号**：DEC-C-0004
- **裁决日期**：2026-10-09
- **状态**：**已裁决 · 已实现 · 已有回归测试**
- **适用阶段**：Alpha A0.2 起（含监考者「注视」减益与后续全部攻速效果）
- **关闭冲突**：设计稿冲突 **C-3**（`docs/A0.2_敌人候选数值设计稿.md`）

### 裁决内容

采用**频率倒数**口径：

```
effectiveAttackSpeedMultiplier = clamp(1 + Σ攻速百分数, floor, ceiling)
effectiveInterval              = baseInterval / effectiveAttackSpeedMultiplier
```

1. 攻速百分数先在**攻击频率**口径下依规格叠加（不同 `effectId` 先相加、与增益统一结算）；
2. 应用已锁定的**上下限**；
3. 再换算为**间隔**。

### 依据与背景

- V2.1.4 **L556（LOCKED）** 原文：「不同 effectId 的攻击、攻击速度、技能 CD 恢复速度减益以『相对基础值的百分数』先相加，再与增益统一结算，最后夹取下限。**有效攻击频率**…不得低于各自基础值的 40%」。
- 规格把 40% 下限明文作用于「**有效攻击频率**」而非「间隔」。因此**频率倒数读法是唯一与规格自洽的读法**。
- 「间隔直接 × (1+|Σ|)」的读法会使减益侧与增益侧（+X% ⇒ ×(1+X)）不对称，破坏 L556「减益与增益统一结算」，故**排除**。
- 上限来自**表 81**（L2108）「攻击速度加成｜局内总增益原则上不超过 +80%」，即系数上限 1.8。L2113 明标「以上均为测试基线，不是最终数值」，故上限**可配置、非 LOCKED**。
- 下限存于 `balance.json` 的 `combat.debuffFloor`（L557 要求）；上限存于 `combat.buffCeiling`。

### 明确不做 / 现状边界

- 上限当前**不可达**：A0.3 构建**无局内强化系统**（属 A0.6），没有任何攻速增益来源。`combat.buffCeiling.enforced = false` 如实标注此事，**不得宣称该上限已通过实战验收**；
- 不实现攻速的递减收益（表 81 的「同类增益过多时使用递减收益」属 A0.6 局内构筑）；
- 不改变沉默（控制类）的行为——L557 明文沉默**不改变普通攻击频率**。
