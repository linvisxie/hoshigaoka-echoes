# 0.5.15 经验条、校园切换与校门牌修正

- 培养页经验条使用独立的蓝色进度样式，移除误套用的卡片装饰。填充按实际经验比例显示，高光限制在填充内部；左侧经验条与右侧保持一致。
- 学习记录类型按钮移除越过切角边框的矩形高光，保留现有悬停皮肤。
- 学生手册及继续调查入口在源场景完整绘制后采集画面，使用既有 0.55 秒柔和过渡覆盖切换间隙。异步按钮增加重复点击拦截与对象有效性检查。冷加载仍有短暂停顿，未宣称消除所有加载耗时。
- 活动室、教学楼、弓道场、保健室的悬停灯光改用局部加法增亮。实测活动室门窗区域中英文、720p/1080p 平均亮度增加约 18%，避免只有暖色覆盖却没有变亮。保留闲置背景配色与菜单位置。
- 关卡记录移除底部操作提示。校门牌复用标题页同一绘制方法，含正式校徽与竖排校名，随背景覆盖缩放定位；英文模式也与标题页一致。
- 保健室与调查卡继续调查的悬停强调线按图片可见边框定位，修正上下留白不等。点击矩形与文字位置保持原样。
