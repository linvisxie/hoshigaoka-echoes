# 0.5.13 校园环境与交互动效

校园保留原有构图、文字与点击区域，新增三层樱花、统一风向的枝叶与纸页轻动、前景局部鼠标视差、门窗暖光、地点悬停反馈、新记录提示呼吸光、天空残响轨迹、调查卡与弹窗淡入，以及短暂点击反馈。

雨宫澪沿用当前语言对应的原校园图纹理，通过局部轮廓网格实现轻微呼吸、发梢摆动、偶尔侧身与悬停回应；眨眼只转移局部眼睑编辑的像素差值，保留原图配色。没有额外头顶黄字或交谈提示框。点击人物短暂反馈后仍进入原地点交谈列表，不改变剧情解锁、资源或奖励规则。

动效位于原生控件下方，独立效果层不接收鼠标；模态窗口或窗口失焦时停止局部交互动效。点击期间忽略重复激活，Esc 取消待执行跳转，防止旧点击在关闭菜单后继续生效。环境音效使用短时、限频的原创弓弦和纸页合成音，复用现有 SFX 总线及音量设置。

标题、资源栏、学生手册、调查卡及左下角声波提示区域，连同半透明面板背后的背景，都排除在前景变形范围之外。测试中人物、公告板的透明热区不再用静态矩形贴图盖住动画。
