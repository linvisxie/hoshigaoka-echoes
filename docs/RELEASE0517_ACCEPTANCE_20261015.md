# 0.5.17 装备提示与结算修正

本版修复装备操作提示不消失、强化预览显示负数、结算卡片遗漏装备奖励三处问题。

- 装备操作提示显示三秒；同页刷新保留原截止时间，新操作重新计时，退出页面后清除。
- 资源不足时只显示需求与当前持有，禁止确认；不会预扣其他资源或显示负数余额。后续按用户要求删除了“缺少”整行，中英文同步。
- 结算卡片展示本次结算新增的装备名称、图标、数量与“前往装备背包领取”提示，包括校园纪念物。多项奖励可滚动。背包领取流程保持原样，重复通关不会重复显示首通装备。

剧情档案、按钮反馈、页面过渡及已取消的“跳过已读”没有改动。

## 验证与边界

- GUT：45 个脚本、655 项测试、13,434 次断言通过。
- 提示和强化预览：1280×720、1920×1080，中英文各覆盖；每种分辨率 29 项检查通过。
- 结算卡片：两种分辨率、中英文、多个真实关卡奖励配置，验证首通、重复、失败、纪念物、文字边界、图标与滚动。数据经过实际结算服务；测试手动设定胜利状态，属于结算与渲染验证，不代表完整战斗试玩。
- 最终 EXE：中英文共 40 项真实 Windows 输入检查通过，包含三次实际强化、提示更新与过期、离开重进、资源不足时禁用确认。报告绑定 EXE/PCK 哈希。
- 强化成功流程使用隔离的正常通关存档副本；资源不足场景使用隔离边界样本，仅将副本装备零件设为 0，元数据随验收材料保留。自动测试不修改真实玩家存档。
- 最终验收截图和报告见“实机验证/实机对照.html”。早期选错资源场景的失败记录保留在外部测试目录，不纳入通过证据。
- 正常退出仍有历史已有的 17 项静态 GDScript 资源保留 / 30 项 ObjectDB 提示；本版未处理该独立问题，没有新增脚本解析或纹理加载错误。

发布时另行备份真实存档及设置，逐文件校验后迁移到新版本。ZIP 不包含玩家存档，保留 0.5.16 供回退。
